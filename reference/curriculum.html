Exgester Mastery — 5-Week Curriculum

📅 ~35 sessions ⏱️ 1–2 hours per day 🎯 Goal: Independently modify & maintain Exgester
Knowledge Learn concept (30 min) Skill Hands-on exercise Build Add to your project Project Milestone build Review Recall + quiz

Every day has a concrete build task. You learn the concept for ~30 min, then spend the remaining time coding. All exercises and acceptance criteria are in the Hands-On Exercises doc.

How to use this

Start each session with /teach. I'll deliver the concept lesson, then you code the exercise yourself. If you get stuck, ask me — I'll guide without spoiling the answer.

Progressive Build Strategy

Weeks 1–2: Standalone Java files in a week1/ / week2/ folder. No Spring yet.
Week 3: You create a Spring Boot Maven project and start building the real app.
Weeks 4–5: You refactor and extend that same project until it's a working mini-Exgester.

Week 1 — Java Foundations & Functional Thinking

Build language fluency. All exercises are standalone Java files in week1/.

Day 1: OOP & SOLID in 60 Minutes
Knowledge Build
Learn the five SOLID principles with Exgester-flavored examples. Then refactor a monolithic TradeProcessor class into 4 SOLID classes.

→ Exercise E1: SOLID Trade Refactor
Day 2: Generics — Reading Exgester's Type Signatures
Knowledge Build
Bounded types, wildcards (? extends, ? super), type erasure. Build a generic pipeline interface.
Source: Effective Java, Items 26–33
→ Exercise E2: Generic DecisionStep Interface
Day 3: Functional Interfaces & Lambdas
Knowledge Build
Function, Predicate, Consumer, Supplier, method references. Build a configurable trade filter using lambdas.
Source: Effective Java, Items 42–44

Build

Source: Effective Java, Items 45–48
→ Exercise E4: Stream Analytics Dashboard
Day 5: Optional & Immutability

Optional API, immutable value objects, final fields. Build the trade domain model you'll use for the entire course.
Source: Effective Java, Items 17, 55
→ Exercise E5: Immutable Trade Domain Model
Day 6: Functional Composition & Higher-Order Functions
Knowledge Build

Week 2 — Vavr & Railway-Oriented Programming

The most critical week. Create a week2/ Maven project with Vavr. Reuse your domain model.

Knowledge Build

→ Exercise E8: Either Fundamentals Kata
Day 10: 🏗️ Building Your First Decision Pipeline
Build Project
THE MOST IMPORTANT EXERCISE. Build a 4-step decision pipeline with Either<RejectionReason, TradeContext>. Chain with flatMap. See short-circuiting in action.
Source: Baeldung — Vavr Either

Day 11: Advanced ROP — peek, mapLeft, filterOrElse

Day 13: Side-Effect Isolation — Pure Core, Imperative Shell
