Exgester Mastery — 4-Week Curriculum

📅 20 sessions (4 weeks) ⏱️ 1–2 hours per day 🎯 Goal: Independently modify & maintain Exgester
Knowledge Learn concept (30 min) Skill Hands-on exercise Build Add to your project Project Milestone build

Every day has a concrete build task focused on creating a "MiniExgester" application from scratch.

How to use this

Start each session with /teach. I'll deliver the concept lesson, then you code the exercise yourself. If you get stuck, ask me — I'll guide without spoiling the answer.
