🚂 Vavr & Railway-Oriented Programming

Either from Scratch

/teach Teach me Vavr Either from the ground up. I want to understand the two-track mental model, map vs flatMap, and how to build a simple 3-step decision pipeline. Include a hands-on exercise.

Pipeline Debugging

/teach Give me a broken Either pipeline (6+ steps) with 2-3 subtle bugs. I want to practice debugging ROP code — finding where the wrong track is taken, where map should be flatMap, etc.

Advanced Either Operations

/teach Teach me the advanced Either operations I'll need in Exgester: mapLeft for error transformation, peek for side-effect logging, filterOrElse for conditional rejection, and how to compose multiple Either-returning functions into a clean pipeline.

Try and Option

/teach Teach me Vavr Try and Option. Show me how they bridge imperative exception-throwing code into functional pipelines, and how to convert between Try → Either and Option → Either.
☕ Java Fundamentals

Generics Deep Dive

/teach Teach me Java generics at the level needed to read Exgester. Cover bounded types, wildcards (? extends, ? super), type erasure, and give me exercises writing generic interfaces like DecisionStep.

Functional Interfaces & Lambdas

/teach Teach me Java functional interfaces and lambdas. I need to understand Function, Predicate, Consumer, Supplier, BiFunction, and method references well enough to read and write Exgester's functional-style code.

Streams Mastery

/teach Give me a streams workout. I want exercises that practice map, filter, flatMap, collect, reduce, and groupingBy using trade event data. Focus on the operations I'll see in Exgester.
🌱 Spring Boot

Spring Profiles for Multi-Tenant

/teach Teach me how Exgester uses Spring @Profile to serve multiple banks from one codebase. Cover profile activation, profile-specific beans, custom profile annotations, and profile-specific YAML. Include a hands-on exercise where I create two client profiles with different behavior.

Constructor Injection & DI

/teach Teach me Spring dependency injection the way Exgester uses it. Focus on constructor injection with @RequiredArgsConstructor, @Configuration classes, @Bean methods, and how pipeline steps are wired together as Spring beans.

YAML Configuration

/teach Teach me Spring YAML configuration. I need to understand hierarchical config, @ConfigurationProperties, profile-specific YAML (application-{profile}.yml), and type-safe config binding. Exercise: model a regulatory config in YAML.
📨 JMS & Messaging

JMS Fundamentals

/teach Teach me JMS concepts as they apply to Exgester: Queue vs Topic, message types, acknowledgment modes, dead-letter queues. Then show me how Spring JMS works with @JmsListener and JmsTemplate.

End-to-End Message Flow

/teach Walk me through building a mini app that receives a JSON trade event from a JMS queue, processes it through a Vavr Either pipeline, and sends the result to an output queue. I want to understand the full message flow.
🏗️ Design Patterns

Strategy + Spring Profiles

/teach Show me how the Strategy pattern combines with Spring Profiles in Exgester. I want to build a ReportabilityStrategy interface with EMIR and CFTC implementations, injected via profiles.

Pattern Recognition Exercise

/teach Give me code snippets that use Strategy, Factory, Template Method, Chain of Responsibility, Composite, and Builder patterns. I need to identify which pattern each snippet uses and explain why.
🧪 Testing

Cucumber BDD for Trade Reporting

/teach Teach me Cucumber BDD testing for trade reporting scenarios. Show me how to write Gherkin feature files like "Given a trade event for ANZ, When the decision engine runs, Then an EMIR submission should be created." Include step definition implementation.

Testing Either Pipelines

/teach Teach me how to unit test Vavr Either decision pipelines with JUnit 5. Cover: asserting isRight/isLeft, extracting values, testing individual pipeline steps, and testing the full pipeline end-to-end.
🏛️ Regulatory Domain

Trade Reporting Crash Course

/teach Give me a crash course on regulatory trade reporting — just enough domain knowledge to understand why Exgester exists. Cover EMIR, FCA, ASIC, CFTC at a high level: what they require, key identifiers (LEI, UTI, UPI), and the lifecycle of a reported trade.
🏆 Capstone

Build Mini Exgester

/teach I'm ready for the capstone project. Guide me through building a mini trade reporting engine that combines all the skills: JMS messaging, Either pipelines, Spring profiles for multi-tenant, Strategy pattern for regulatory rules, Cucumber tests, and Maven build. Walk me through it step by step.

Code Review Practice

/teach Give me a code review exercise. Show me a trade reporting pipeline implementation with 5-8 code quality issues (pattern violations, missing error handling, side effects in wrong places, etc). I want to find and fix them all.
