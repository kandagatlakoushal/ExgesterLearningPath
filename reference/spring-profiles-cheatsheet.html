Spring Profiles for Multi-Tenant Apps — Quick Reference

📖 Reference Document 🔗 Spring Boot Profiles Docs

Activating Profiles

# Command line
java -jar exgester.jar --spring.profiles.active=anz,emir

# application.yml
spring:
  profiles:
    active: anz

# Environment variable
SPRING_PROFILES_ACTIVE=anz,emir

Profile-Specific Beans

@Service
@Profile("anz")
public class AnzReportabilityStrategy implements ReportabilityStrategy {
    // ANZ-specific reporting rules
}

@Service
@Profile("wbc")
public class WbcReportabilityStrategy implements ReportabilityStrategy {
    // WBC-specific reporting rules
}

@Service
@Profile("default")
public class DefaultReportabilityStrategy implements ReportabilityStrategy {
    // Fallback for unmatched profiles
}

Custom Profile Annotations

// Exgester pattern: custom annotations for readability
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Profile("anz")
public @interface AnzProfile { }

// Usage — cleaner than @Profile("anz")
@Service
@AnzProfile
public class AnzTradeFilter { ... }

Profile-Specific YAML Configuration

# application.yml (shared config)
reporting:
  max-retry: 3
  timeout-ms: 5000

# application-anz.yml (ANZ-specific overrides)
reporting:
  regions:
    - ASIC
    - EMIR
  anz-specific:
    include-fx-forwards: true

# application-wbc.yml (WBC-specific overrides)
reporting:
  regions:
    - ASIC
  wbc-specific:
    legacy-format: true

Binding YAML to Java

@ConfigurationProperties(prefix = "reporting")
@Data // Lombok
public class ReportingConfig {
    private int maxRetry;
    private int timeoutMs;
    private List<String> regions;
}

Profile Operators

ExpressionMeaning
@Profile("anz")Active only when "anz" is active
@Profile("!anz")Active when "anz" is NOT active
@Profile({"anz", "wbc"})Active when "anz" OR "wbc" is active
@Profile("anz & emir")Active when BOTH "anz" AND "emir" are active
@Profile("anz | wbc")Active when "anz" OR "wbc" is active
How Exgester uses this

Exgester runs as one deployed application but serves multiple banks. At startup, profiles like anz,emir,asic are activated. This causes Spring to wire only ANZ-specific beans and EMIR/ASIC regulatory config. The same JAR, different wiring — that's the multi-tenant magic.
