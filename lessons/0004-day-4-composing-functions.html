Day 4: Composing Functions (Building the Railway)

Yesterday, we learned that Either<L, R> represents a value that is either an error (Left) or a success (Right). Today, we learn how to chain multiple validation functions together to build a complete pipeline.

In Exgester, a trade might go through 10-20 distinct checks. If any check fails, the trade is rejected and processing stops.

1. The Pipeline Blueprint

Let's define three distinct validation functions:


public Either<String, Trade> hasValidId(Trade trade) {
    return trade.tradeId() == null || trade.tradeId().isBlank() 
        ? Either.left("Missing Trade ID") 
        : Either.right(trade);
}

public Either<String, Trade> hasValidNotional(Trade trade) {
    return trade.notional() <= 0 
        ? Either.left("Invalid Notional: " + trade.notional()) 
        : Either.right(trade);
}

public Either<String, Trade> isSupportedRegion(Trade trade) {
    return List.of("EMIR", "ASIC", "CFTC").contains(trade.region())
        ? Either.right(trade)
        : Either.left("Unsupported Region: " + trade.region());
}

2. Chaining with flatMap

Because each function returns an Either<String, Trade>, we can chain them together using flatMap. Remember: flatMap only executes the next function if the current state is a Right!


public Either<String, Trade> processTrade(Trade rawTrade) {
    return hasValidId(rawTrade)
        .flatMap(this::hasValidNotional)
        .flatMap(this::isSupportedRegion);
}
The Beauty of FlatMap

Look at how clean that processTrade method is! There are no if statements. There are no try/catch blocks. The control flow (the short-circuiting on failure) is entirely abstracted away by the Either monad.

3. Peeking at the Tracks

What if you want to log the trade at a certain step, but you don't want to modify the pipeline? Vavr provides the peek and peekLeft methods.


public Either<String, Trade> processTrade(Trade rawTrade) {
    return hasValidId(rawTrade)
        .peek(t -> log.info("Trade ID is valid: {}", t.tradeId()))
        .flatMap(this::hasValidNotional)
        .flatMap(this::isSupportedRegion)
        .peekLeft(error -> log.error("Trade rejected: {}", error));
}
