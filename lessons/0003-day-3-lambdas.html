Day 3: Functional Interfaces & Lambdas

🎯 Week 1: Java Foundations ⏱️ 45 minutes

To master Vavr and Exgester's pipeline, you must be comfortable treating functions as data. Java 8 introduced Functional Interfaces (interfaces with a single abstract method) and Lambdas to make this clean and concise.

The Core Functional Interfaces

InterfaceSignatureUse Case in Exgester
Function<T, R>R apply(T t)Transforming a TradeEvent into a TradeContext
Predicate<T>boolean test(T t)Filtering trades (e.g., is notional > 5000?)
Consumer<T>void accept(T t)Side-effects, like logging a rejection
Supplier<T>T get()Lazy evaluation, creating default values

Method References

Often, a lambda just calls an existing method. You can use :: syntax for brevity:

// Lambda
trades.forEach(t -> System.out.println(t));

// Method Reference
trades.forEach(System.out::println);
